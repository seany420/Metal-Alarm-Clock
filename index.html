The Summoning

Snooze gives you 9 minutes. Killing it means holding the button for 2 seconds, so you have to be at least half awake.

The Setlist

Each alarm plays the next song down the list, then wraps back to the top. Tap Load on a slot and pick the song file from your phone (MP3, M4A, whatever you own). Slots without a file get skipped. If nothing is loaded you get a built-in riff with a tolling bell.

    The Backdrop

    Put any picture behind the clock: your favorite slasher still, an album cover, a shot of your own haunted bedroom. It gets washed into grayscale so the blood stays red.

    Keep it alive

    • Leave this page open overnight. Phones freeze background web pages, so the alarm only goes off while this screen is up. Tap Nightstand mode before bed.
    • Plug the phone in and turn the volume up. If the screen still dims, raise Auto-Lock (iPhone) or Screen timeout (Android) while it charges.
    • Tap anything once after opening the page. Browsers only allow sound after you've touched the page.
    • Run Test alarm the first night so you know it's loud enough.
